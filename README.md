# 棱镜 PRISM — A股行情模拟交易 APP（含战绩分享）

纯前端 + 轻量 Node 后端的炒股应用原型。真实行情、模拟交易、K线图表、财经快讯、社区，并支持**生成只读战绩分享链接**——别人打开就能看到你的实时持仓与交易记录。

## 快速启动

```bash
cd stock-app
node server.js 8823        # 零依赖，无需 npm install
```

- APP：`http://localhost:8823`
- 数据目录：`stock-app/data/db.json`（账户令牌与分享快照）

## 战绩分享（核心功能）

1. **我的 → 编辑**：设置昵称和策略标签
2. **我的 → 分享我的战绩 → 生成分享链接**
3. 得到形如 `http://你的地址/s/AbCdEf12` 的链接，发给任何人
4. 对方打开后进入**只读战绩页**，每 30 秒自动刷新：
   - 累计收益率、总资产、收益曲线
   - 当前持仓与浮动盈亏
   - 最近 50 笔交易（买卖方向、价格、已实现盈亏）
   - 卖出胜率、交易笔数、仓位

安全设计：
- 分享页**只读**，无法操作你的账户；操作接口全部要求私有令牌（`X-Account-Key`）
- 快照只包含展示字段，资金明细中的敏感信息不外传
- 可随时在 APP 内**停用**链接，停用后立即失效
- 令牌存于本地浏览器；清除浏览器数据后重新打开 APP 会自动创建新账户

## 功能总览

| 模块 | 说明 |
|---|---|
| 自选 | 指数卡片 + 自选列表 + 搜索（代码/名称/拼音） |
| 行情 | 涨跌幅/成交额/换手/涨速榜、行业板块热力图 |
| 详情 | 日/周/月 K 线（MA/MACD/成交量，拖动缩放十字光标）、分时+均价线、五档盘口、基本面 |
| 交易 | 模拟撮合：佣金万 2.5、印花税 0.05%、T+1、涨跌停校验；交易即自动同步云端 |
| 资讯 | 7×24 快讯、要闻（东方财富） |
| 社区 | 讨论区（本地） |

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/account` | 创建账户，返回令牌 |
| POST | `/api/sync` | 上传战绩快照（需令牌头 `X-Account-Key`） |
| POST/DELETE | `/api/share` | 生成 / 停用分享链接（需令牌） |
| GET | `/api/share/:id` | 公开读取战绩快照 |
| GET | `/s/:id` | 只读分享页 |
| GET | `/px?url=` | 行情代理（白名单域名） |

## 部署到公网

任意能跑 Node 的主机（云服务器、VPS、Docker）：

```bash
git clone <你的仓库> && cd stock-app
node server.js 80            # 或用 PM2 / systemd 守护
```

需放行端口并确保 `data/` 目录可写。没有公网主机时，可用内网穿透（frp、cloudflared 等）把本机 8823 暴露出去。
